# QueryDraft

関係図と表を往復しながら、欲しいデータをSQLで取り出す学習ワークスペース。

## 起動

Node.js 22以降で `npm ci` → `npm run build` → `npm start`。表示されたURLをブラウザで開きます。file://で直接開かず、HTTPサーバーを使用してください。

`dist/` は静的配信可能です。GitHub Pagesならこのディレクトリを配布します。CIが配布用artifactを作成しますが、このPRでは公開設定・自動デプロイを行いません。

## 使い方

1. テーブルの列名を選択してSELECTへ追加。
2. 表の値を選ぶか、条件欄からWHEREを設定。
3. 関連テーブルの列を選ぶと外部キーからJOINを生成。
4. 「実行する」でブラウザ内SQLiteの結果を確認。
5. 各テーブルの表示切替、INNER/LEFTの切替、並べ替え、下部解説で比較。

ヘッダーのドラッグで表を移動できます。モバイルでは関係図の横スクロールを使えます。データ・条件はページを閉じると消えます。

## 構成・検証

- `src/data.js`: 教材と外部キー
- `src/query.js`: 表示と独立したクエリモデル／SQL生成
- `src/app.js`: 表・関係図の共有選択状態
- `src/worker.js`: SQLite実行
- `npm test`: SQLiteで生成クエリの結果・NULL・多段JOIN・値の引用を検証
- `docs/design.md`: 会話とVaultを反映した設計判断・後続範囲

実行エンジンはsql.js（MIT）を配布物に同梱。教材データは架空です。初版は教材1種類で、CSV/Excel取込・自由入力SQL・複数解法は未実装です。
